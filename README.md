# LexiBridge
English vocabulary/dictionary website built with Node.js, Express, HTML, CSS and JavaScript.

## Install
1. Open this folder in Visual Studio Code.
2. Open Terminal.
3. Run `npm install`.
4. Rename `.env.example` to `.env`.
5. Put your Gemini API key in `.env`.
6. Run `npm start`.
7. Open http://localhost:3000

The app uses dictionary evidence first and Gemini for structured grammatical analysis. WordReference is linked for manual verification; it is not scraped.
